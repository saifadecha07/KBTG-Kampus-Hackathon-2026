Proposed Solution

Sapling ต่อยอดจากฟีเจอร์ ePocket ที่ K PLUS มีอยู่แล้ว ผ่านกลไก 3 ส่วนที่ทำงานร่วมกันโดยที่ผู้ใช้ไม่ต้องโยกเงินเอง

Auto-Split ตอนเงินเข้า
เมื่อเงินเดือนเข้าบัญชี ระบบจะถามผู้ใช้ก่อนเสมอว่าต้องการแบ่งเงินตามแผนหรือไม่ แล้วจึงแบ่งเข้าบัญชีย่อยสามส่วน คือเงินกันไว้จ่ายบิล เงินออมในนิรภัย และเงินใช้จ่ายรายวัน หากตั้งให้จดจำผู้ส่ง รอบถัดไปจะทำงานอัตโนมัติทันที ใช้ได้ทั้งพนักงานประจำและฟรีแลนซ์ที่รายได้เข้าไม่ตรงงวด
Daily Auto-Refill
ทุกเที่ยงคืน ระบบจะเติมเงินในกระเป๋ารายวันให้ครบตามเป้าที่ตั้งไว้จากบัญชีเงินเดือน หากใช้เกินเป้าในวันนั้น ระบบจะไม่ปิดกั้นการใช้จ่าย แต่จะแจ้งเตือนพร้อมยอดคงเหลือให้เห็นทันที
กระเป๋านิรภัย (Vault)
เงินในกระเป๋านี้จะถอนออกไม่ได้ทันที ต้องรอผ่านช่วงเวลาที่กำหนดไว้ก่อน แล้วระบบจะปล่อยเงินให้อัตโนมัติ แนวคิดนี้อ้างอิงจากงานวิจัยด้าน commitment device (Ashraf, Karlan & Yin, QJE 2006) ที่ยืนยันว่าผู้ใช้ยอมรับกลไกลักษณะนี้ได้จริงแม้ไม่มีผลตอบแทนพิเศษ

Target Users

ผู้ใช้ K PLUS อายุ 22–30 ปี กลุ่ม First Jobbers ที่รายได้ปานกลางถึงจำกัด เช่น พนักงานออฟฟิศเงินเดือน 22,500 บาทที่เข้าตรงเวลาทุกเดือน หรือฟรีแลนซ์ที่ลูกค้าโอนเงินไม่ตรงงวด คนกลุ่มนี้มีรายรับแต่จัดสรรเงินเองไม่ทัน โดยเฉพาะกลุ่มที่เช่าบ้านหรือคอนโดในเมืองซึ่งค่าครองชีพสูงเมื่อเทียบกับรายได้

Track Perspective — Track 1

ในด้านการพัฒนา ทีมออกแบบ rule engine ให้แยกเป็นโมดูลที่ทดสอบง่าย กำหนดให้สถานะของช่วงเวลารอถอนเงินต้องอ้างอิงจากเซิร์ฟเวอร์เท่านั้น และบันทึกทุกรายการผ่าน ledger ที่เขียนได้ทางเดียวเพื่อป้องกันข้อมูลผิดเพี้ยน

ในด้านการทดสอบ ทีมใช้ property test สุ่มธุรกรรมกว่าหมื่นรายการเพื่อยืนยันว่ายอดเงินในทุกบัญชีถูกต้องเสมอ ร่วมกับ unit และ integration test ที่ครอบคลุมกรณีย่อยกว่า 50 จุดที่สำรวจไว้ล่วงหน้า และทดสอบ idempotency กับ concurrency โดยเฉพาะ

ในด้านการรับประกันคุณภาพ ทีมวางแผนทดสอบการใช้งานจริงกับผู้ใช้ 5–8 คนตาม protocol ที่กำหนดไว้ล่วงหน้า พร้อมจัดทำ checklist ตามหลัก PDPA เพื่อดูแลข้อมูลส่วนบุคคล

Value Proposition

ผู้ใช้

ผู้ใช้ไม่ต้องแบ่งเงินเอง เห็นเงินออมของตัวเองเติบโตขึ้นอย่างเป็นระบบ และมีเวลาคิดทบทวนมากขึ้นก่อนจะใช้เงินก้อนที่ออมไว้ ซึ่งในกรณีที่กำลังจะโอนเงินออมให้มิจฉาชีพโดยไม่ทันคิด ช่วงเวลารอนี้อาจช่วยลดความเสียหายได้บ้าง

K PLUS

ฟีเจอร์นี้ช่วยเพิ่มความถี่ในการเปิดใช้แอป เปิดโอกาสต่อยอดผลิตภัณฑ์ออมทรัพย์จากพฤติกรรมผู้ใช้จริง และสร้างความแตกต่างที่ชัดเจนจาก Cloud Pocket ของ MAKE by KBank และ Lock Account เดิมของ K PLUS ซึ่งยังไม่มีกลไกปลดล็อกอัตโนมัติในระดับกระเป๋าย่อยแบบนี้
