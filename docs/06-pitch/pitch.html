Problem Statement

First Jobbers ไทยจำนวนมากบริหารเงินเดือนไม่ทัน และเป็นกลุ่มเสี่ยงสูงต่อการถูกหลอกลวงทางการเงิน: Gen Z ไทย 63% และ Gen Y ไทย 64% ใช้เงินเดือนหมดพอดีทุกเดือน ไม่มีเหลือเก็บ สูงกว่าค่าเฉลี่ยโลกที่ 52% (Deloitte Global 2025) — คนอายุ 21–30 เป็นกลุ่มเหยื่อหลักของ scam ในไทย ความเสียหายเฉลี่ย 12,956 บาท/คน (GASA/Nation Thailand, พ.ย. 2025) — เงินเดือนแรกเข้าของบัณฑิตจบใหม่ 25.6% อยู่ในช่วง 15,001–30,000 บาท (JobsDB) สวนทางค่าครองชีพในเมือง และคนไทยกว่า 70% มีเงินสำรองฉุกเฉินไม่ถึง 3 เดือน (SCB EIC Outlook Q2/2024)

Proposed Solution

Sapling ต่อยอดจาก ePocket เดิมของ K PLUS ด้วย 3 กลไกที่ทำงานร่วมกัน:

  • Auto-Split ตอนเงินเข้า — เงินเดือนเข้า ระบบเด้งถามยืนยัน (ไม่เดาว่าก้อนไหนคือเงินเดือน) แล้วแบ่งเข้า 3 บัญชีอัตโนมัติ: กันเงินบิลที่หักอัตโนมัติไว้ก่อนเสมอ / นิรภัย / รายวัน — ติ๊ก "จำไว้" ครั้งแรกแล้วอัตโนมัติเต็มรูปแบบรอบถัดไป รองรับทั้งพนักงานประจำและฟรีแลนซ์ด้วยกลไกเดียวกัน
  • Daily Auto-Refill — เติมกระเป๋าใช้จ่ายรายวันจากบัญชีเงินรายเดือนทุกเที่ยงคืนตามเป้าที่ตกลง ใช้เกินได้ไม่บล็อก แต่แจ้งเตือนพร้อมยอดคงเหลือบัญชีหลักแบบ real-time
  • กระเป๋านิรภัย (Vault) — เงินออมถอนออกไม่ได้ทันที ต้องรอ cooldown (ตั้งครั้งเดียวตอนเปิดบัญชี) แล้วปล่อยเงินอัตโนมัติในแอป ไม่ต้องไปสาขา — ต่างจาก K PLUS Lock Account เดิมที่ล็อกทั้งบัญชีและต้องไปสาขาเพื่อปลด

Target Users

ผู้ใช้ K PLUS อายุ 22–30 ปี กลุ่ม First Jobbers รายได้ปานกลาง–จำกัด มีรายรับสม่ำเสมอ (พนักงานประจำหรือฟรีแลนซ์) แต่จัดสรรเงินเองไม่ทัน โดยเฉพาะกลุ่มเช่าบ้าน/คอนโดในเมืองที่ค่าครองชีพสูงเทียบกับรายได้

Track Perspective — Track 1

Develop: rule engine แยก module ทดสอบง่าย · cooldown state authoritative ที่ server เท่านั้น · ledger เขียนอย่างเดียว 2 ขา

Test: Property test สุ่มธุรกรรม 10,000 รายการ ยืนยันผลรวมทุกกระเป๋าตรงเสมอไม่มีกระเป๋าติดลบ · unit/integration ครอบทุก edge case จากการไล่ตรวจ use case อย่างเป็นระบบ (53 จุด) · idempotency/concurrency test

Ensure Quality: usability test 5–8 คนตาม protocol ที่กำหนด task/เกณฑ์ตัดสินไว้ล่วงหน้า · PDPA checklist เพราะระบบเก็บข้อมูลเงินเดือนและพฤติกรรมใช้จ่าย

Value Proposition

ผู้ใช้

K PLUS

เพิ่ม engagement รายวัน ต่อยอดขาย product ออมทรัพย์จากพฤติกรรมผู้ใช้ จุดต่างชัดจาก MAKE Cloud Pocket และ K PLUS Lock Account เดิม — cooldown ปลดอัตโนมัติในแอประดับกระเป๋า ไม่ใช่ล็อกทั้งบัญชีที่ต้องไปสาขา
